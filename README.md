## Project Overview

This project was developed as apart of the Software Engineering Capstone Project.

The Owl Eye Monitor project will develop a system used to emulate stress tests on the KSU servers. By simulating real-world stress scenarios to generate controlled system problems such as CPU spikes, memory overloads, log errors, and database transaction failures. As well as using a Grafana-based Monitoring & Alerting system to visualize system metrics using Prometheus, detecting anomalies, sending notifications, and executing auto-resolution strategies.
